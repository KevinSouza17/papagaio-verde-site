# Papagaio Verde

Site institucional da loja Papagaio Verde.

## Identidade visual

- Mascote: papagaio verde com bico amarelo.
- Cores principais: verde-escuro e verde vibrante.

## Objetivo

Apresentar a loja, seus produtos e serviços, facilitar o contato e permitir solicitações de orçamento pelo WhatsApp.

## Próximas etapas

- Desenvolver a página inicial responsiva.
- Criar seções de catálogo, sobre a loja e contato.
- Configurar links de contato e botão flutuante do WhatsApp.
- Revisar a identidade visual e os arquivos de logo/favicons aprovados.
